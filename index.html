Cargá sus resultados y compar.ar calcula el margen y lo ubica en el rango. El ajuste de patrimoniales es opcional: lo prende el analista.

Este archivo no trae la hoja Data con los financieros crudos, así que no puedo calcular el ajuste de patrimoniales. Podés cargar los resultados igual para ubicar el margen sin ajustar.

Con el ajuste desactivado alcanza con ventas, costo y gastos. Activá "Aplicar ajuste" para habilitar las columnas de patrimoniales.

¿Qué fórmula aplica cada ajuste patrimonial?
Cuentas a cobrar (sobre ventas) Ventasaj = Ventas − ( (CtasCobrarTP / VentasTP × Ventascomp − CtasCobrarcomp) × i / (1 + i) )
Cuentas a pagar (sobre costo) Costoaj = Costo − ( (CtasPagarTP / VentasTP × Ventascomp − CtasPagarcomp) × i / (1 + i) )
Inventarios (sobre costo, si no es servicios) Costoaj = Costoaj − ( (InventariosTP / VentasTP × Ventascomp − Inventarioscomp) × i )

i = tasa de interés del año · TP = empresa analizada · comp = cada comparable. Con Ventasaj y Costoaj se recalcula el margen de cada comparable, y de ahí el rango ajustado.
